# INSTRUCCIONES DEL PROYECTO - DERECHOS ART

ESTE ARCHIVO CONTIENE LAS REGLAS ESPECIFICAS PARA EL DESARROLLO Y FLUJO DE TRABAJO DE ESTE REPOSITORIO.

## FLUJO DE TRABAJO Y GIT
- **CONFIRMACION DE SUBIDA:** CADA VEZ QUE SE REALICE UN CAMBIO EN EL CODIGO, EL AGENTE DEBE PREGUNTAR AL USUARIO SI DESEA SUBIR LOS CAMBIOS AL REPOSITORIO DE GIT (PUSH). NO SE DEBEN REALIZAR COMMITS NI PUSH AUTOMATICOS SIN CONSENTIMIENTO EXPRESO.

- **AUTONOMIA DE EJECUCION:** EL USUARIO PREFIERE QUE EL AGENTE ACTUE CON AUTONOMIA TOTAL AL EJECUTAR UNA DIRECTIVA. UNA VEZ QUE EL OBJETIVO ESTA CLARO, EL AGENTE DEBE PROCEDER CON LA INVESTIGACION Y EJECUCION DE CAMBIOS SIN PEDIR CONFIRMACION PASO A PASO, INFORMANDO LOS AVANCES A TRAVES DEL MODELO DE TOPICOS.

## ESTANDARES DE CODIGO
- **IDIOMA:** TODOS LOS NOMBRES DE VARIABLES, FUNCIONES, CLASES Y ARCHIVOS DEBEN ESTAR EN CASTELLANO (PASCALCASE).
- **COMENTARIOS:** DEBEN ESTAR SIEMPRE EN ESPAÑOL, EN MAYUSCULAS Y SIN ACENTOS.
- **MENSAJES EN PANTALLA:** CUALQUIER TEXTO QUE SE MUESTRE AL USUARIO FINAL (LOGS, PRINTS, INTERFAZ) DEBE ESTAR EN MAYUSCULAS Y SIN ACENTOS.
